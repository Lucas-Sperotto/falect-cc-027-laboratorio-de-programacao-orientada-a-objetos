## Objetivo deste repositório

Este repositório organiza:

- materiais da disciplina;
- roteiros de aula;
- atividades;
- práticas de laboratório;
- projeto integrador;
- orientações de entrega;
- critérios de avaliação;
- políticas de GitHub e uso de IA.

## Estrutura

- `aulas/`: roteiros e materiais por encontro
- `ead/`: vídeos e atividades EAD, quando houver
- `atividades/`: listas, laboratórios e projeto
- `rubricas/`: critérios de avaliação
- `templates/`: modelos de entrega
- `docs/`: PPC, plano e documentos de apoio
- `exemplos/`: códigos e exemplos discutidos em aula

## Ferramentas da disciplina

- VS Code

- [linguagem da disciplina]

## Como estudar nesta disciplina

1. Leia o roteiro da aula.
2. Reproduza os exemplos.
3. Faça a atividade prática.
4. Documente minimamente seu trabalho.
5. Versione corretamente.
6. Respeite as regras de uso de IA da atividade.
7. Tire dúvidas cedo.
