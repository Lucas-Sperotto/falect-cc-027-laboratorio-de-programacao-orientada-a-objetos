# Registro de Decisões do Template-Base

Este arquivo foi mantido apenas como memória do processo de consolidação do repositório-base. Ele não precisa ser copiado para os repositórios finais das disciplinas.

## 1. Identidade docente

- Nome público: Prof. Me. Lucas Kriesel Sperotto
- Contato público: perfis profissionais publicados no GitHub do professor
- Texto de apresentação docente: apoiar-se em IA com prompt orientado em `PROMPTS_IA.md`

## 2. Escopo da base

- esta base serve como `template geral` para padronizar o planejamento das disciplinas;
- a intenção é copiar esta estrutura para cada disciplina e adaptar manualmente os dados específicos;
- o material de aula pode ficar no GitHub e também no SIGAA, conforme a necessidade da oferta.

## 3. GitHub e SIGAA

- o `forking workflow` será obrigatório nas atividades versionadas e de laboratório;
- a entrega formal no SIGAA será feita por relatório curto em PDF com link da atividade;
- a disciplina pode combinar entrega técnica no GitHub com registro formal no SIGAA;
- deve haver padrão para nomes de `branch`, pastas de atividade e mensagens de `commit`;
- o critério relevante é qualidade da documentação e clareza do código, não quantidade de comentários.

## 4. Uso de IA

- as atividades devem ser marcadas explicitamente como `IA permitida` ou `IA não permitida`;
- em atividades com IA permitida, podem ser fornecidos prompts-guia ou prompts prontos;
- não haverá declaração obrigatória de uso de IA em toda entrega;
- em avaliações presenciais e práticas individuais, a regra inicial é restringir o uso de IA, salvo autorização explícita.

## 5. Metodologia

- o resumo final breve ao término de cada encontro será prática fixa;
- o formato preferencial desse resumo é texto breve individual;
- nas disciplinas com EAD, a ideia inicial é trabalhar com vídeos curtos distribuídos ao longo dos 15 encontros;
- nas disciplinas sem EAD formal, vídeos curtos podem existir como material complementar, sem compor carga horária.

## 6. Linguagens e ferramentas

- Algoritmos e Laboratório de Programação I: C
- Algoritmos e Laboratório de Programação II: C/C++
- Estrutura de Dados I: C/C++
- Estrutura de Dados II: C/C++
- Laboratório de Programação Orientada a Objetos: a definir por oferta, com possibilidade de Java, C++ ou Python
- Processamento de Alto Desempenho: C/C++ com foco em OpenMP, MPI e CUDA
- VS Code: ambiente padrão, com extensões recomendadas por disciplina

## 7. Observação final

As decisões acima já foram incorporadas aos documentos principais desta base. O arquivo fica apenas como histórico de trabalho e apoio futuro, caso seja útil revisar o raciocínio que levou à estrutura atual.
