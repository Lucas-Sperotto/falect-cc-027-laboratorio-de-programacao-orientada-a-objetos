# Atividades

Use este diretório para listas, laboratórios, projetos e etapas.

Sugestão de nomes:

- `lista-01`
- `laboratorio-01`
- `projeto-integrador`
- `projeto-etapa-01`

Cada atividade deve indicar com clareza:

- objetivo;
- critérios de entrega;
- regra de uso de IA;
- formato de entrega no GitHub;
- registro esperado no SIGAA.
